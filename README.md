# ChatBot-IFS

This project was conducted by myself as the part of the second year project of our team. This is Chatbot designed for IFS community page to increase efficiency of the feedback system.

Teck Stack
  FrontEnd - React Js
  API - Flask
  Database - MongoDB
  VectorStore - DeepLake
  Chatbot Backend - OpenAI, Langchain, Beautifulsoup
